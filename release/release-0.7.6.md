# POWER-GUI 0.7.6

POWER-GUI 0.7.6 is the GUI half of the POWER 3.7.1 candidate/stable suite
boundary. It uses the `power.application.v2` contract and supports Python
`>=3.13,<3.15`.

The release workflow publishes the wheel, sdist, SPDX SBOM, provenance
attestation, and a hash-bound receipt. The paired POWER core tag and the
container image digest are verified separately before the suite is called
stable.
